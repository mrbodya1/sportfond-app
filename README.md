# Sportfond App — «9000 км»

Рабочая версия в ветке `recovery`. Ветка `main` и публичная заглушка не изменены.

## Что реализовано

- Адаптивный интерфейс: главная, регистрация/вход, кабинет, история, таблица, администрирование и документы.
- Настоящий вход по одноразовому коду Beget: 10 минут, 5 попыток, пауза повторной отправки 60 секунд. Сессия до 30 дней в HttpOnly cookie; на сервере хранится хеш.
- SQLite: пользователи, версии согласий, тренировки, решения и журнал действий. Исходных демонстрационных записей нет.
- Скриншот сохраняется вне публичного каталога. Его видит только владелец или администратор через защищённый API.
- OpenAI вызывается только сервером, после нажатия кнопки «Отправить». Ключи не передаются в браузер.
- Если дата, положительная дистанция и GPS уверенно распознаны, тренировка сразу засчитывается. Даты — с 29 октября 2026 года включительно, без будущих дат; темп и пульс не проверяются.
- Неоднозначные данные и похожая тренировка с той же датой/дистанцией переходят на ручной разбор. Одинаковый файл не зачисляется повторно, в том числе после удаления. Хеш совпавшего изображения другого участника блокируется.
- Общий результат и личная статистика строятся только по подтверждённым неудалённым записям. Остальные участники в таблице отображаются под номерами профилей.
- Роль администратора определяется только серверной настройкой `ADMIN_EMAILS`, не параметрами браузера.

## Локальный запуск

Node.js 20.19+ или 22.12+, Python 3.11+; у Python только стандартная библиотека.

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4174
```

Адрес: http://127.0.0.1:4174/. Vite проксирует `/api` на `127.0.0.1:18766`. Запуск Python и расположение данных — в [docs/LOCAL-APP.md](docs/LOCAL-APP.md). Без API интерфейс сообщает о недоступности сервера и не подставляет примеры.

Страницы: `/#home`, `/#registration`, `/#account`, `/#history`, `/#leaderboard`, `/#admin`; документы `/rules/`, `/policy/`, `/consent/`.

## Проверки и сборка

```sh
python -m unittest discover -s backend -p 'test_*.py'
npm run build
node --test tests/sites-worker.test.mjs tests/pwa.test.mjs tests/training-rules.test.mjs
```

14 Python-проверок, в том числе HTTP-сценарий с изолированной БД и подменёнными SMTP/OpenAI; они не отправляют реальные письма и не расходуют квоту. 11 Node-проверок охватывают правила, PWA и статическую сборку. Windows-песочница может блокировать локальные сокеты HTTP-тестов; запускать в разрешённом окружении или на домашнем Linux.

Готовый фронтенд: `dist/client`; Sites runtime: `dist/server/index.js` и `dist/.openai/hosting.json`. Для GitHub Pages используют только `dist/client`. Статический хостинг не запускает Python и сам по себе не подключает домашний API.

## Ограничения перед публичным запуском

Сейчас API и интерфейс работают локально на компьютере владельца. Обработчик привязан к loopback и не включён в публичный Cloudflare Tunnel. Не переключать Pages на `recovery` до отдельной подготовки публичного API: HTTPS, Secure-cookie, доверенный origin, проксирование API, автозапуск, резервное копирование и утверждённый порядок хранения/удаления файлов. После этого нужна проверка регистрации и загрузки владельцем с реальной почтой.

Защита от дублей использует SHA-256 изображения и совпадение даты/дистанции в профиле. Она не гарантирует выявление каждого отредактированного изображения; подозрительные совпадения проверяет администратор.

## Дизайн и документы

Палитра: #1E3A8A, #3B82F6, #22D3EE, #F8FAFC; Montserrat/Open Sans локально через Fontsource, иконки Phosphor. Сохранён утверждённый дизайн и адаптивная сетка.

Политика и согласие предоставлены владельцем. Правила обновлены по его условиям: только бег с GPS с 29.10.2026. Реквизиты и документы находятся в `src/legal/`. Принятие правил и согласие — отдельные активные действия, по умолчанию отметки сняты. Версия и время согласия фиксируются при подтверждении почты.

PWA кэширует только статическую оболочку, исключая API, POST, изображения участников и сторонние запросы. При обновлении неотправленное изображение потребуется выбрать заново; история остаётся на сервере.

Не помещать в GitHub `.env`, ключи, базы, резервные копии и изображения участников.
