# Sportfond App — восстановление интерфейса

Ветка recovery: новый адаптивный прототип. Основная ветка main и её заглушка не изменены.

## Запуск

Node.js 20.19+ или 22.12+ и npm:

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4174
```

Открыть http://127.0.0.1:4174/

Страницы: /#home, /#registration, /#account.
Сборка: npm run build. Статические файлы находятся в dist/client.
Проверки подготовленного Sites runtime: npm run test:sites.
Для GitHub Pages публикуется только dist/client, а не dist/server.

## Демонстрационный режим

Форма принимает имя, email и согласие, затем показывает код 123456. Письмо не отправляется. Кабинет содержит явно обозначенные примерные данные. Загрузка проверяет тип и размер до 5 МБ, показывает изображение локально. Изображения, имя и email не отправляются на сервер и не сохраняются после перезагрузки. Это не настоящая авторизация.

## Следующие этапы

1. Защищённый серверный вход по email-коду, ограничения запросов и сессии.
2. Авторизованная загрузка изображений: серверная проверка формата и размера, хранение вне публичного каталога, сроки удаления.
3. Вызовы OpenAI/GigaChat только с сервера. Ключи — в серверном окружении вне GitHub и браузера.
4. Очередь распознавания, ручная модерация, база тренировок, общий прогресс и таблица.
5. Полные правила, политика данных и доступный preview перед заменой заглушки.

## Дизайн

Утверждённые макеты: ../design/app-v1 в рабочей папке. Палитра #1E3A8A, #3B82F6, #22D3EE, #F8FAFC. Montserrat и Open Sans поставляются локально через Fontsource; иконки Phosphor. Фон и растровый логотип подготовлены по предоставленным материалам. Ширины проверяются от 320 px; на широких экранах форма и кабинет используют колонки.

Не переключать GitHub Pages с main на recovery: текущая публичная заглушка должна оставаться до готовности приложения. CNAME наследуется от main, но эта ветка не публикуется автоматически.
## Проверенные варианты
- Ширины 320, 390, 768 и 1440 px.
- Компьютер: двухколоночная форма и кабинет. Телефон: один столбец, нижняя навигация.
- Регистрация/вход демонстрационные, без запросов к API.
- Последняя тренировка и километры — примеры.

## Новые разделы

- /#admin — открытая демоадминка: фильтры, поиск, изменение зачётной дистанции, подтверждение/отклонение с причиной, участники и журнал изменений в текущей сессии. Рабочих административных API нет.
- /#rules — проект правил участия.
- /#privacy — проект политики обработки данных.
- /#consent — отдельный проект согласия.

В форме регистрации две независимые отметки, изначально снятые. Все юридические документы требуют реквизитов оператора и окончательных условий до реального запуска. Почта и план регистрации описаны в docs/MAIL-AND-REGISTRATION.md. SMTP-диагностика и её тесты находятся в backend; это не сервер авторизации.
