# Распознавание OpenAI — локальный тест

## Что подключено

Запрос идёт из локального интерфейса через Vite-прокси на домашний Python-обработчик, затем в OpenAI Responses API. По умолчанию используется gpt-4.1-mini, параметр OPENAI_MODEL позволяет выбрать другую совместимую модель. Ключ читается только сервером из защищённого окружения; ни в браузере, ни в GitHub его нет.

Результат: дата, километры, наличие GPS, тип активности и краткое пояснение. Темп, длительность, пульс и координаты маршрута не извлекаются. Используется JSON Schema со строгим форматом, но бизнес-правила всё равно проверяет сервер. Приложение задаёт store=false; это не обещание отсутствия любой обработки/хранения на стороне поставщика.

## Проверка в интерфейсе

1. На компьютере открой http://127.0.0.1:4174/#account.
2. Убедись, что выбран режим «OpenAI · реальная проверка».
3. Выбери JPG, PNG или WEBP до 5 МБ.
4. Подтверди отправку выбранного изображения в OpenAI и нажми «Распознать через OpenAI».
5. Проверь дату, км и GPS. Неоднозначный результат требует ручного разбора; явно не соответствующий правилам не добавляется. Результат с определёнными датой и км можно добавить только в тестовую очередь.

Это не официальный зачёт и не настоящая авторизация участника. Рабочие серверные сессии, права администратора, хранение тренировок и журнал согласий ещё не подключены. Публичная заглушка не изменена.

## Сервер

Python 3.11+; внешние пакеты не требуются. Запуск из каталога проекта:

```sh
python3 backend/recognition_server.py --env-file /private/path/openai.env --data-dir /private/runtime/data --port 18766
```

В защищённом env-файле: OPENAI_API_KEY, необязательно OPENAI_MODEL. Не размещать файл внутри репозитория и не передавать сам ключ аргументом команды. Путь в примере условный.

Сервис слушает только 127.0.0.1:18766. Внешняя публикация и Cloudflare Tunnel для этого обработчика не настроены. Открывать его в интернет до серверной авторизации нельзя. Vite нужно запускать с --host 127.0.0.1; домашний WSL передаёт локальный порт Windows.

Тестовый процесс сейчас запускается вручную; автоматический запуск после перезагрузки ещё не настроен.

## Ограничения

- Один выполняющийся запрос и не более 10 новых обращений в час на тестовый сервис.
- Изображения принимаются только как Base64; удалённые URL не загружаются.
- На диск изображение не сохраняется. В SQLite остаются хеш и ответ распознавания; клиентский preview и очередь — только в памяти вкладки.
- Повторный файл получает сохранённый ответ без нового запроса к модели. Это кэш распознавания, а не полный механизм защиты зачёта от дублей.
- Похожий/изменённый скриншот и достоверность самой тренировки требуют дальнейших проверок. Модель не доказывает, что человек действительно пробежал маршрут.
- Неизвестная дата или год не заменяются предположениями. Зачёт начинается 29 октября 2026 включительно; будущие даты исключены.
- Перед реальным использованием данных участников нужно завершить рабочий контур доступа, хранения, обработки данных и правовые условия выбранного поставщика.

## Проверки

```sh
python3 -m unittest discover -s backend -p 'test_*.py'
```

Проверены соединение с OpenAI, доступ к модели и реальная обработка тестового логотипа: дата/км не определены, GPS отсутствует, результат не зачислен. Из браузера также пройден путь выбора изображения и получения настоящего ответа. Качество на реальных скриншотах пробежек пока не оценено.
